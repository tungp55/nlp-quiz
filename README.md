# NLP Ôn tập – Quiz & Flashcard (Bài 1–6)

436 câu trắc nghiệm (262 theo slide + 174 bổ sung kiến thức) và phần tóm tắt kiến thức từng bài cho môn Xử lý ngôn ngữ tự nhiên.

- Chế độ: Quiz, Flashcard, Ôn câu sai, Bảng ôn, Tóm tắt (có công thức, render bằng KaTeX/MathML).
- Lọc theo bài, độ khó, nguồn câu hỏi.
- Mobile: vuốt trái/phải để sang câu tiếp sau khi trả lời; flashcard vuốt phải = đã thuộc, trái = chưa thuộc.
- PWA: cài ra màn hình chính, dùng offline. Tiến độ lưu trong trình duyệt của từng người.
- Khi cập nhật: sửa `index.html` và đổi `VERSION` trong `sw.js`.
